# 이영찬

사용자와 가장 먼저 만나는 화면을 만드는 **프론트엔드 개발자**


<br />

## 저를 소개합니다


프론트엔드는 사용자와 가장 먼저 만나는 자리라고 생각합니다.
그래서 제가 만든 화면 앞에서 사용자가 불편함을 겪지 않는 것을 가장 앞에 둡니다.

기다리게 하지 않는 것, 헤매게 하지 않는 것,
무엇이 잘못됐는지 모른 채 멈춰 있게 하지 않는 것.
그 정도를 지키는 개발자가 되려고 합니다.
